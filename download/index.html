装好之后怎么用

  1. 打开软件双击桌面「AI 模型网关」，首次会等几秒初始化
  2. 输入卡密激活把你买到的卡号填进去，验证通过即生效
  3. 填入你自己的上游 Key三家永久免费通道，见软件里的《免费 API 注册指南》，不填也能先用自带通道
  4. 完事网关地址 http://127.0.0.1:8000/v1 ，客户端/IDE 里选这个就能调
